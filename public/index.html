Engineered for macOS Workflows

Four pinning modes. Zero compromises.

Standard macOS apps cannot float arbitrary third-party windows without injecting code into the Dock process. PinTop solves this cleanly using Apple's native frameworks.

📌 1:1 Pin (In-Place) Best for Specs & Docs

Native interaction when clear, 60fps mirror when covered

Keeps the target window pinned in its exact screen coordinates. While uncovered, all clicks, scrolling, and typing go directly to the native window. The instant another app overlaps it, a 60fps zero-copy IOSurface mirror seamlessly takes over—and a single click brings the real window forward.

Occlusion polling + AXRaise 100% Opacity default
👻 Ghost (Click-Through) Best for Pixel Diffing & Tutorials

Translucent floating reference you can click right through

Projects a customizable translucent overlay (25%–100% opacity) with ignoresMouseEvents = true. Keep a design mockup, terminal log, or API spec hovering right over your IDE while every mouse click and scroll gesture passes straight through to the code underneath.

Global toggle: ⌃⌥G 78% Opacity default
🖼️ PiP (Picture-in-Picture) Best for Live Streams & Dashboards

Turn any macOS window into a resizable mini monitor

Shrinks any full-sized browser, simulator, or build log into a crisp aspect-locked floating mini-window anchored to the corner of your display. Drag anywhere on screen or resize from any corner while the source window stays out of your way.

Aspect-ratio preserving 60fps SCStream
↗️ Auto-Raise Best for Active Utility Windows

Automatic native window elevation via Accessibility

Monitors Z-order window stacking across your display and automatically raises the real native macOS window back to the top whenever an overlapping window covers its bounds—keeping the real window 100% native at all times.

Download PinTop for macOS

Pre-built, ad-hoc signed release bundle (com.pintop.mac) for Apple Silicon Macs running macOS 14.0 Sonoma or newer. Free and open-source.

  1. 1 Download and extract PinTop-macOS-arm64.zip, then drag PinTop.app into your /Applications folder.
  2. 2 Open PinTop.app. If macOS Gatekeeper prompts on first launch, right-click → Open (or run xattr -cr PinTop.app).
  3. 3 Grant Screen Recording and Accessibility permissions so the top-right status badges show Screen OK and AX OK.
